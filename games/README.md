# games/

Installed game packs live here, one folder per title:

```
games/
  treasure_hunt/manifest.json
  fantasy/manifest.json
  spooky_deluxe/manifest.json
  mystery/manifest.json
```

Packs are generated from your own discs with `python -m ispytools install <iso-or-folder>`
and are intentionally git-ignored. See `tools/README.md` for the full pipeline.
